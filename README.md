# Indian E-Commerce Customer Behavior & Sales Analytics

## Project Overview

This project analyzes customer behavior and sales performance in an Indian e-commerce dataset. The analysis focuses on revenue, purchases, customer activity, conversion rate, product categories, marketing channels, device types, and purchasing behavior.

Python was used for data cleaning, exploratory data analysis, statistical analysis, correlation analysis, outlier detection, and visualization. Power BI was used to create an interactive dashboard for business analysis.

## Problem Statement

E-commerce businesses generate large amounts of customer and transaction data. Analyzing this data can help businesses understand customer purchasing behavior, identify high-performing areas, improve conversion rates, and make better marketing and business decisions.

The objective of this project is to analyze e-commerce customer behavior and sales data and provide meaningful business insights and recommendations.

## Key Business Insights

- The dataset contains 25,000 customer visits and generated approximately ₹10.12 million in total revenue.
- The overall purchase conversion rate is 22.46%.
- Product Category Code 2 generated the highest revenue at approximately ₹2.04 million.
- Product Category Code 6 was the second-highest revenue-generating category.
- Marketing Channel Code 5 generated the highest revenue and purchase activity.
- Device Type Code 1 contributed the highest total revenue at approximately ₹5.01 million.
- User Type Code 1 showed stronger purchasing behavior than User Type Code 0.
- Cart abandonment represents an important opportunity for improving customer conversion.

## Business Recommendations

1. Improve the checkout process to increase the conversion rate.
2. Reduce cart abandonment through a simpler purchasing process and customer reminders.
3. Focus marketing efforts on high-performing marketing channels.
4. Give additional promotional attention to high-performing product categories.
5. Optimize the shopping experience across different device types.

## Conclusion

This project demonstrates how Python and Power BI can be used together to transform e-commerce data into meaningful business insights. The analysis helps identify revenue patterns, customer purchasing behavior, high-performing categories and channels, and opportunities for improving conversion and reducing cart abandonment.
